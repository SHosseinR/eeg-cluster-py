# NSGA-II Optimization Module for EEG Connectivity

## Overview

This module implements a multi-objective optimization framework using NSGA-II (Non-dominated Sorting Genetic Algorithm II) to identify optimal brain stimulation parameters for improving network connectivity in patient populations.

## Key Features

- **Multi-objective optimization** using NSGA-II algorithm
- **State-space simulation** of EEG dynamics with stimulation
- **Plasticity-based connectivity updates** modeling brain adaptation
- **Comprehensive visualization** of optimization results
- **Modular design** for easy customization and extension

## Workflow

```
1. Load pre-computed connectivity matrices and network measures
2. Determine optimization directions (min/max) based on Patient vs Healthy comparison
3. For each Patient subject:
   a. Compute baseline activation from raw EEG
   b. Run NSGA-II to find optimal (node, frequency_band) combinations
   c. For each candidate solution:
      - Simulate state-space dynamics with stimulation
      - Update connectivity based on plasticity rules
      - Compute network measures on updated connectivity
   d. Return Pareto-optimal solutions
4. Visualize and analyze results across all patients
```

## Optimization Process

### 1. Objective Determination

For each network measure:
- Compute average across all Patient subjects and all frequency bands
- Compute average across all Healthy subjects and all frequency bands
- If Patient avg > Healthy avg: **MINIMIZE** (reduce to healthy level)
- If Patient avg < Healthy avg: **MAXIMIZE** (increase to healthy level)

### 2. State-Space Dynamics

The brain dynamics are modeled as:

```
dx/dt = A*x - A*xbar + B*u
x(0) = xbar
```

Where:
- `A`: Normalized adjacency matrix (connectivity)
- `x`: Node activation state
- `xbar`: Baseline activation
- `B`: Control matrix (selects stimulation node)
- `u`: Stimulation input

### 3. Plasticity Updates

After stimulation, connectivity is updated based on Hebbian-like plasticity:

```
E_new(i,j) = E(i,j) * (R_i * R_j)
```

Where:
- `E(i,j)`: Connection strength from node i to node j
- `R_i, R_j`: Activation ratio for nodes i and j

### 4. NSGA-II Optimization

**Decision Variables:**
- Stimulation node (0 to n_nodes-1)
- Frequency band (0 to n_bands-1)

**Objectives:**
- 3 network measures (minimize or maximize)

**Algorithm:**
1. Initialize random population
2. Evaluate objectives for each individual
3. Non-dominated sorting (find Pareto fronts)
4. Calculate crowding distances
5. Select parents via tournament selection
6. Create offspring via crossover and mutation
7. Combine parents and offspring
8. Select next generation (elitism)
9. Repeat for n_generations

## Interpreting Results

### Node Histogram

Shows which brain regions (channels) are most frequently selected as optimal stimulation targets across patients. Higher bars indicate nodes that are commonly identified as optimal.

### Band Histogram

Shows which frequency bands are most frequently selected. This indicates which oscillatory rhythms are most important for therapeutic stimulation.

### Node-Band Heatmap

Shows the joint distribution of optimal node and band combinations. Hot spots indicate particularly effective node-band pairs.

### Pareto Fronts

For subjects with multiple competing objectives, the Pareto front shows trade-offs. Points on the front represent solutions where improving one objective requires compromising another.

## Troubleshooting

### Issue: Optimization takes too long

**Solutions:**
- Reduce `population_size` and `n_generations` in config
- Optimize fewer subjects for initial testing
- Use parallel processing (requires code modification)

### Issue: No meaningful differences found

**Solutions:**
- Check that Patient and Healthy groups show clear differences in network measures
- Try different network measures
- Adjust `stability_constant` if simulation is too stable/unstable
- Increase `plasticity_scaling` for stronger effects

### Issue: Memory errors

**Solutions:**
- Process fewer subjects at a time
- Reduce population size
- Increase `dt` (larger time steps, but less accurate)

### Issue: Unstable simulations

**Solutions:**
- Increase `stability_constant` to make dynamics more stable
- Check adjacency matrices for invalid values (NaN, Inf)
- Reduce `stimulation_amplitude`

## Theory and Methods

### NSGA-II Algorithm

NSGA-II is a multi-objective evolutionary algorithm that:
1. Maintains population diversity through crowding distance
2. Uses non-dominated sorting for Pareto optimization
3. Employs elitism to preserve good solutions
4. Handles multiple conflicting objectives simultaneously

**Reference:** Deb et al. (2002). "A fast and elitist multiobjective genetic algorithm: NSGA-II." IEEE Transactions on Evolutionary Computation.

### State-Space Modeling

Linear state-space models capture network dynamics:
- Widely used in control theory and neuroscience
- Captures propagation of activity through network
- Allows simulation of interventions (stimulation)

**Reference:** Strogatz (2015). "Nonlinear Dynamics and Chaos."

### Hebbian Plasticity

"Neurons that fire together, wire together":
- Connections between co-activated nodes strengthen
- Connections between non-co-activated nodes weaken
- Biologically plausible learning mechanism

**Reference:** Hebb (1949). "The Organization of Behavior."
